# Epicycle Ink

A public, exploratory web app where anyone (including kids) can play with spinning circles, draw a closed line and see it encoded as circles, watch kolams being drawn, export a 9:16 video, and learn what Fourier series are along the way (started for Inktober 2026). 

Try it here: https://bhargavimahesh.github.io/epicycles/ (#circles = mode 1, #draw = mode 2, kolam.html = page 3).
